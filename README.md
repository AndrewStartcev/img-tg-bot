# img-tg-bot

Приватный Telegram-бот для локального **Qwen-Image-2.1** на NVIDIA GPU.

Без ComfyUI и без внешнего image-generation API:

```text
Telegram
  ↓
aiogram
  ↓
QwenImage21Pipeline / Diffusers
  ↓
NVIDIA GPU
  ↓
PNG обратно в Telegram
```

Поддерживает:

- генерацию картинки по тексту;
- редактирование присланной фотографии по текстовой инструкции;
- обязательный префикс-пароль в начале каждого запроса;
- удаление пароля перед отправкой текста в модель;
- дополнительный whitelist по Telegram user ID;
- long polling — открывать порты наружу не нужно;
- systemd — бот сам стартует после включения сервера;
- временные входные изображения не сохраняются на диск.

## Рекомендуемый сервер

Проверочная конфигурация:

- Ubuntu 24.04;
- NVIDIA Tesla A10 24 GB;
- CUDA 12.8;
- 32 GB RAM;
- 128 GB SSD.

По умолчанию используется `addlabsviral/Qwen-Image-2.1-4bit`: Diffusers-сборка Qwen-Image-2.1, в которой transformer и Qwen3-VL text encoder упакованы в 4-bit FP4, а VAE остаётся BF16. Это значительно снижает требования к VRAM.

## 1. Создать Telegram-бота

Через **@BotFather**:

1. `/newbot`
2. создать бота;
3. скопировать token.

Token **не коммитить в Git**.

## 2. Установка на сервере

```bash
git clone https://github.com/AndrewStartcev/img-tg-bot.git
cd img-tg-bot

cp .env.example .env
nano .env
```

Минимально заполни:

```env
TELEGRAM_BOT_TOKEN=123456:YOUR_TELEGRAM_TOKEN
ACCESS_PREFIX=1234
```

Затем:

```bash
sudo bash install.sh
```

Скрипт:

1. проверит NVIDIA;
2. установит системные зависимости;
3. создаст `.venv`;
4. поставит PyTorch CUDA 12.8;
5. поставит Diffusers/Qwen/aiogram;
6. создаст systemd unit;
7. включит автозапуск;
8. запустит бота.

Вес модели будет скачан с Hugging Face при первом `/warmup` или первой генерации. После этого останется в `HF_HOME` и при следующем включении сервера повторно скачиваться не должен.

## Использование

### Генерация

Сообщение:

```text
1234 Фотореалистичный чёрный автомобиль ночью на мокрой улице, cinematic
```

В модель попадёт только:

```text
Фотореалистичный чёрный автомобиль ночью на мокрой улице, cinematic
```

`1234` удаляется до вызова Qwen.

### Редактирование

Отправь фотографию и добавь подпись:

```text
1234 Убери очки. Лицо, волосы, одежду, фон и освещение не меняй.
```

Бот передаст Qwen исходное изображение + текст без `1234` и вернёт PNG.

Можно отправлять как обычное Telegram Photo или как image Document. Для исходника без дополнительного Telegram-сжатия лучше отправлять файлом.

### Команды

Все команды тоже требуют пароль:

```text
1234 /status
1234 /warmup
1234 /help
```

`/warmup` заранее загружает модель в GPU.

## Дополнительная защита

Одного пароля `1234` мало для публичного бота, особенно если этот репозиторий публичный.

Рекомендуется узнать свой Telegram user ID и добавить его в `.env`:

```env
ALLOWED_USER_IDS=123456789
```

Можно несколько:

```env
ALLOWED_USER_IDS=123456789,987654321
```

Тогда сообщения от других аккаунтов бот полностью игнорирует.

## Настройки

`.env`:

```env
GENERATE_WIDTH=1024
GENERATE_HEIGHT=1024
EDIT_MAX_SIDE=1024
INFERENCE_STEPS=30
TRUE_CFG_SCALE=1.0
SEND_AS_DOCUMENT=true
MODEL_LOAD_ON_START=false
```

На A10 24 GB лучше сначала оставить 1024×1024. Увеличение разрешения резко повышает расход VRAM.

Для редактирования входная фотография автоматически уменьшается до `EDIT_MAX_SIDE`, сохраняя пропорции.

## Управление

Статус:

```bash
systemctl status img-tg-bot --no-pager
```

Логи:

```bash
journalctl -u img-tg-bot -f
```

Перезапуск:

```bash
sudo systemctl restart img-tg-bot
```

Остановка:

```bash
sudo systemctl stop img-tg-bot
```

Обновление из Git:

```bash
cd img-tg-bot
bash update.sh
```

## После выключения GPU-сервера

systemd остаётся настроенным на диске. Когда сервер снова включится, бот автоматически запустится.

Если модель уже скачана в `HF_HOME`, повторно качать десятки гигабайт не потребуется.

## Секреты

В репозиторий не попадают:

- Telegram bot token;
- Hugging Face token;
- Telegram user IDs из `.env`.

`.env` добавлен в `.gitignore`.
